# Super Schoon – website

Broncode van www.superschoon.be (Super Schoon by S&S Projects).
Elke push naar `main` wordt via de webhook automatisch door OVH online gezet in de map `www`.

- Pagina's: `*.html` in de hoofdmap
- Opmaak en scripts: `assets/`
- Formulierverwerking (offerte en contact): `verstuur.php`
- Prijsberekening: `assets/js/calculator.js` (functie `berekenPrijs`) en `verstuur.php` (functie `prijsReiniging`) moeten gelijk blijven.

Zet nooit wachtwoorden, sleutels of klantgegevens in deze opslagplaats.
